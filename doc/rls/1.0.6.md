## Release 1.0.6 – Changelog Summary

UI refinement release that replaces the per-page native HTML `<select>` with a native Bootstrap dropdown component.

* **Per-Page Dropdown**
  Replaced the `form-select` between the Show/entries labels with a Bootstrap 5.3 dropdown (`btn btn-outline-secondary` toggle button plus `dropdown-menu`) driven by Bootstrap's bundled JavaScript via `data-bs-toggle="dropdown"`.
  The current page size is highlighted as the active item and shown on the toggle button; the control now matches the height of the search input.
* **Event Delegation for Page Size Selection**
  The selection handler is delegated to a single click listener on the stable `.dropdown-menu` element, so it survives re-renders of the menu items when the API returns a different per page value.
  Clicks inside the menu that do not hit an item are ignored.
* **Documentation Updates**
  Renamed "per-page select" to "per-page dropdown" in the JSDoc and both README language sections.
* **Version Bump Across Assets**
  Updated distributed files, headers, package metadata, and CDN snippets to 1.0.6.
  Keeps npm, jsDelivr, and Packagist references in lockstep with the new tag.

**Compatibility**: Backward compatible
