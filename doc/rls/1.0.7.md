## Release 1.0.7 – Changelog Summary

Feature release that adds horizontal scrolling with fixed (sticky) columns to AvalynxDataTable.

* **Fixed Columns via `fixed` Column Property**
  Column definitions returned by the API now support an optional `fixed` property with the values `'start'` or `'end'`.
  Columns marked as fixed stay pinned to the left or right edge while the table scrolls horizontally (`position: sticky`), e.g. for action buttons or row identifiers.
* **Horizontal Scroll Container**
  The table is now wrapped in a `.avalynx-datatable-responsive` container (`overflow-x: auto`) so wide tables scroll horizontally on small screens and touch devices.
* **Separate Border Model for Sticky Cells**
  Switched the wrapped table to `border-collapse: separate` with one-sided cell borders, because browsers drop collapsed borders on `position: sticky` cells.
  Refined the border and shadow handling for `table-bordered` and non-bordered instances so fixed cells keep visible delimiters in both variants.
* **Empty Cell Rendering**
  Empty cell values (`null`, `undefined`, or empty string) are now rendered as `&nbsp;` to keep row heights consistent.
* **New Scrolling Example**
  Added `examples/datatable-scrolling.html` together with `examples/php/result-scroll.php` demonstrating a wide table with fixed start and end columns.
* **Documentation Updates**
  Documented the new `fixed` column property and the scrolling example in both READMEs.
  Fixed documentation drift: `apiUrl` and `className` defaults, the `sorting` format description (object with column ids as keys), and the `showingFilteredEntries` default text now match the actual code in the JSDoc and both READMEs.
* **Version Bump Across Assets**
  Updated distributed files, headers, package metadata, and CDN snippets to 1.0.7.
  Keeps npm, jsDelivr, and Packagist references in lockstep with the new tag.

**Compatibility**: Backward compatible
