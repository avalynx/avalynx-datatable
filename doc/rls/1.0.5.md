## Release 1.0.5 – Changelog Summary

Documentation and tooling maintenance release that aligns the README, JSDoc, and project-wide conventions across the Avalynx library family. No runtime or API changes.

* **Project-Wide README Alignment**
  Harmonised the section order, badges, and wording of `README.md` and `README.de.md` with the rest of the Avalynx packages.
  Provides a consistent reading experience and makes cross-package navigation predictable.
* **JSDoc Style Standardisation**
  Brought the class-level description (`AvalynxDataTable is …`) and `@param` blocks in line with the conventions documented in `AGENTS.md`.
  No behaviour changes; only the documented contract.
* **Centralised AI Agent Instructions**
  Added a unified `AGENTS.md` (Docker workflow, 100 % coverage gate, code-style rules) and removed redundant per-tool guidelines.
  Ensures every package receives the same build and documentation expectations.
* **Version Bump Across Assets**
  Updated distributed files, headers, package metadata, and CDN snippets to 1.0.5.
  Keeps npm, jsDelivr, and Packagist references in lockstep with the new tag.

**Compatibility**: Backward compatible
